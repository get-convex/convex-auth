The email + password provider implements password-based login where each
account is identified by a validated email address. It handles:

- Sign-up with email validation: the account is created immediately, but the
  user can sign in only after they open the validation link.
- Sign-in with any verified email address of the account.
- Change password and change email, which require the current password and
  send a security notification to the affected address.
- Password recovery through a reset link that stays valid for 10 minutes.

A validation link works only in the browser that started the flow: the
browser keeps a secret in local storage, and completion requires both that
secret and the code from the link.

Emails are sent through the
[`@convex-dev/resend`](https://www.convex.dev/components/resend) component.

### Install the components

password component stores and verifies the passwords:

### Set up the public backend functions

Set up the provider with `setupEmailPassword` and export the mutations it
hands back once you attach the callback that creates your user rows, in

the emailed links point at:

<include

>
  ../../../../../examples/react-email-password/convex/auth.ts
</include>

The example uses Resend's test mode, where email is only deliverable to
[Resend test addresses](https://resend.com/docs/dashboard/emails/send-test-emails)
such as `delivered@resend.dev`. To send real email, set `testMode: false`
and use a sender address on a domain you verified with Resend.

</Step>
