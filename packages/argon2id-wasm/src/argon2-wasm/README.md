# argon2-wasm

A tiny Rust crate that wraps [`argon2`](https://docs.rs/argon2) and compiles to WebAssembly
via `wasm-bindgen`. It backs the `argon2id-wasm` package, which the password
provider component uses to hash and verify passwords.

## Building

Requires [`just`](https://github.com/casey/just) and the toolchain pinned in
`rust-toolchain.toml` (installed automatically by `rustup` on first use).

```sh
just test   # cargo test
just check  # compile for wasm32 (fast syntax/type check, no bindings)
just build  # regenerate pkg/ via wasm-pack (pinned version)
```

`pkg/` is gitignored and regenerated by `just build`. After changing `src/lib.rs`, run
`just build` (or `pnpm --filter argon2id-wasm build:wasm`) to regenerate it.

The `argon2id-wasm` package's `prepare` script runs `just build` automatically on
`pnpm install` whenever `pkg/` is missing, so a fresh checkout builds it without manual
steps.
